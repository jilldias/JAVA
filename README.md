# Repositório de Estudos em Java

## Descrição

Este repositório foi criado com o objetivo de documentar meus estudos na linguagem **Java** e em tecnologias associadas ao ecossistema backend.

Aqui serão reunidos conteúdos teóricos e práticos, incluindo:

- 📘 Documentação sobre a linguagem Java  
- 🌱 Estudos sobre **Spring Boot** e **Spring Framework**  
- 📦 Gerenciadores de dependência (Maven)  
- 📝 Resumos de conceitos importantes  
- 🔗 Links úteis para materiais de apoio  
- 💻 Arquivos `.java` para prática de sintaxe e recursos da linguagem  

---

## Objetivo

O principal objetivo deste repositório é consolidar o aprendizado em:

- Desenvolvimento backend com Java  
- Construção de aplicações com Spring Boot  
- Estruturação de projetos reais  
- Boas práticas de desenvolvimento  

---

## Estrutura de Aprendizado

Este é um repositório **incremental**, ou seja:

> Novos conteúdos, códigos e anotações serão adicionados conforme o avanço dos estudos.

A ideia é acompanhar a evolução contínua dentro da stack de desenvolvimento backend com Java.

---

## Stack de Interesse

- Java  
- Spring Boot  
- Spring Framework  
- Banco de Dados  
- APIs REST  

---

## Observações

Este repositório serve tanto como material de estudo quanto como histórico de evolução no aprendizado da tecnologia.
